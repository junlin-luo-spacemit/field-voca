# RISC-V 分步学习路线

> 面向零基础学习者。建议按顺序阅读，不需要一开始记住所有术语。
>
> 总原则：先建立“程序如何运行”的直觉，再学习指令、特权、硬件实现和软件生态。

> 阅读提示：每一课都增加了“生活类比”。先用类比建立画面，再回到正式术语和代码；类比用于理解关系，不能替代规范定义。
## 为什么是 RISC-V

**RISC-V 是开源指令集架构**，不同于 x86（Intel/AMD）和 ARM（需要授权）：
- **开源免费**：任何人都可以查看完整规范，实现自己的 CPU，无需授权费。
- **设计简洁**：基础指令集（RV32I）只有 47 条指令，适合从零学习计算机原理。
- **模块化扩展**：可以从最小核心开始，按需添加乘法（M）、浮点（F/D）、向量（V）等扩展。
- **现代设计**：没有 40 年历史包袱，直接采用多核、虚拟化、安全启动等现代概念。

**学习 RISC-V 的迁移能力**：核心概念（取指执行、寄存器、栈、中断、页表、流水线）通用于所有架构。学完 RISC-V 后，理解 ARM/x86 只需查阅指令表差异。

详细对比请参考 [[00-学习导航#RISC-V 与其他架构的区别|架构对比章节]]。

4. 每学完一课，完成其中的"自测问题"，再进入下一课。
5. 遇到陌生术语，先看本路线中的简短解释；需要深入时，再打开"深入阅读"链接。

## 推荐节奏

- 每次学习 30-45 分钟。
- 第一次：只读“核心概念”和示例。
- 第二次：回答自测问题，并打开 1-2 个深入链接。
- 第三次：做一个小实验或用自己的话写总结。
- 不要按词条数量推进；能解释一个概念比读完很多页面更重要。
- 每课先回答三个问题：它像日常生活中的什么？谁在执行动作？数据或控制权去了哪里？
