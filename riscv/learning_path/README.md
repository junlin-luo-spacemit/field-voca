# RISC-V 分步学习路线

> 适合零基础读者。建议按顺序阅读，开始时不必记住太多术语。
>
> 这条路线的想法是：先了解“程序怎么跑起来”，再慢慢补充指令、权限和硬件知识。

> 阅读小提示：每一课都有“生活类比”，先用它帮助理解，再回到正式术语和代码。
## 为什么是 RISC-V

**RISC-V 是开源指令集架构**，不同于 x86（Intel/AMD）和 ARM（需要授权）：
- **开源免费**：任何人都可以查看完整规范，实现自己的 CPU，无需授权费。
- **设计简洁**：基础指令集（RV32I）只有 47 条指令，适合从零学习计算机原理。
- **模块化扩展**：可以从最小核心开始，按需添加乘法（M）、浮点（F/D）、向量（V）等扩展。
- **现代设计**：没有 40 年历史包袱，直接采用多核、虚拟化、安全启动等现代概念。

**学习 RISC-V 的迁移能力**：核心概念（取指执行、寄存器、栈、中断、页表、流水线）通用于所有架构。学完 RISC-V 后，理解 ARM/x86 只需查阅指令表差异。

详细对比请参考 [[00-学习导航#RISC-V 与其他架构的区别|架构对比章节]]。

## 完成本学习路线后你将掌握

- 为什么 RISC-V 和普通计算机不一样，它的设计为什么更简单、开放
- 最常见的 RISC-V 基础指令是什么，它们如何让 CPU 读写数据、算数运算
- 寄存器、内存和栈在程序运行中扮演什么角色
- 怎么把简单的 C 代码和 RISC-V 汇编对应起来，看懂程序是怎么一步步执行的
- 机器如何处理错误和中断，为什么需要不同的运行级别
- 什么是虚拟内存、页表，程序为什么看起来能用比物理内存更多的空间
- RISC-V 的扩展功能有哪些，什么时候会用到乘法、原子操作、向量等能力
- CPU 里流水线、缓存、分支预测这些概念为什么重要，它们怎么影响性能
- 用模拟器、汇编工具和调试工具验证自己的理解，把学习变成动手实践

## 学习建议

- 每次学习 30-45 分钟，保持轻松节奏。
- 第一次：先把主要概念和例子看懂。
- 第二次：做一下自测问题，查一查不懂的词。
- 第三次：动手试一试，或者用自己的话写总结。
- 比起读完很多内容，理解一个概念更重要。
- 可以问自己：这件事像生活中的什么？谁在做事？信息去哪了？
