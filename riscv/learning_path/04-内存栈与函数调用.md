# 04 内存、栈与函数调用

**前置阅读**：[[03-汇编与程序执行|← 03 汇编与程序执行]]

## 你要学什么

上一章你学了寄存器（Register）— CPU 手边的 32 个小格子。但 32 个格子不够用，程序需要更多空间存数据。

**内存（Memory）就是大仓库，栈（Stack）是函数临时借用的工作台。**

### 为什么要学这个？

前面学的都是直线执行的代码，没有函数调用。但真实程序全是函数：`main()` 调用 `add()`，`add()` 调用 `multiply()`...

**这一章解决的问题：**
- 函数怎么传参数、返回结果？
- 调用函数后怎么返回原来的位置？
- 栈是什么？为什么需要它？

学完后，你就能看懂任何函数调用。下一章会教特权架构——程序与操作系统的关系。

---

## 从生活例子开始

想象你在办公室工作：

- **寄存器** = 你桌上的几个文件夹（只能放 32 个）
- **内存** = 办公室的大柜子（能放成千上万个）
- **栈** = 你临时借的一块桌面，用来处理一项任务

当你接到一个任务（调用函数）：

1. 先记下"处理完回到哪里"（返回地址）
2. 在临时桌面上展开工作（局部变量）
3. 完成后收拾干净（释放栈空间）
4. 回到原来的位置继续工作

---

## 寄存器不够用怎么办

假设你要算 10 个数的总和，但寄存器只有 32 个格子，还有很多格子有特殊用途。

这时就需要把数据存到内存（Memory）里。内存就像一个超大数组，每个位置有个地址（Address）。

CPU 不能直接用内存里的数字做计算，必须：

1. **Load（加载）**：把内存里的数字搬到寄存器
2. **计算**：在寄存器里做加减
3. **Store（存储）**：把结果搬回内存

---

## Load 和 Store 指令

RISC-V 里最常见的两个操作：

```asm
lw   a0, 0(a1)     # Load Word：从内存地址 a1+0 读一个数到 a0
sw   a0, 0(a1)     # Store Word：把 a0 的值写到内存地址 a1+0
```

**`lw` = load word（加载一个字）**  
**`sw` = store word（存储一个字）**

举例：

```asm
li   a1, 0x1000    # a1 = 内存地址 0x1000
lw   a0, 0(a1)     # 从地址 0x1000 读数到 a0
addi a0, a0, 5     # a0 = a0 + 5
sw   a0, 0(a1)     # 把 a0 写回地址 0x1000
```

这段代码做了什么？从内存读一个数，加 5，再写回去。

---

## 栈（Stack）是什么

栈是内存里的一块特殊区域，专门给函数临时用。

想象一叠盘子：

- **压栈（Push）**：往上叠一个盘子（存数据）
- **出栈（Pop）**：拿走最上面的盘子（取数据）

**规则：后进先出（Last In, First Out）**

CPU 用一个特殊寄存器 `sp`（Stack Pointer，栈指针）指向栈顶。

## 函数调用的完整流程

假设你有这样的 C 代码：

```c
int add(int x, int y) {
    return x + y;
}

int main() {
    int result = add(3, 5);
}
```

汇编版本大概是这样：

```asm
# main 函数调用 add(3, 5)
main:
    li   a0, 3          # 第一个参数放到 a0
    li   a1, 5          # 第二个参数放到 a1
    jal  ra, add        # 跳转到 add，同时把返回地址存到 ra
    # add 返回后，结果在 a0

# add 函数
add:
    add  a0, a0, a1     # a0 = a0 + a1
    ret                 # 返回（跳回 ra 保存的地址）
```

**关键点：**

1. **参数传递（Parameter）**：用 `a0`、`a1`、`a2`… 这些寄存器
2. **返回地址（Return Address）**：`jal` 指令自动把"回来的地址"存到 `ra` 寄存器
3. **返回值（Return Value）**：结果放在 `a0`
4. **返回**：`ret` 指令跳回 `ra` 保存的地址

## 函数需要栈空间的情况

如果函数只用几个寄存器，不需要栈。但如果：

- 局部变量太多，寄存器放不下
- 函数还要调用别的函数（需要保存 `ra`）

这时就要用栈。

例子：

```asm
my_function:
    addi sp, sp, -16    # 栈指针下移 16 字节（借空间）
    sw   ra, 12(sp)     # 保存返回地址到栈
    sw   s0, 8(sp)      # 保存 s0 的值到栈
    
    # ... 函数的工作 ...
    
    lw   s0, 8(sp)      # 恢复 s0
    lw   ra, 12(sp)     # 恢复返回地址
    addi sp, sp, 16     # 栈指针上移（还空间）
    ret                 # 返回
```

**栈的方向是向下长的**（地址变小），所以"借空间"是 `sp - 16`，"还空间"是 `sp + 16`。

## 你现在能做什么

看到这样的代码：

```asm
li   a0, 10
li   a1, 20
jal  ra, my_func
```

你应该能回答：

- 参数是什么？（10 和 20，放在 a0 和 a1）
- 函数返回后，结果在哪？（a0）
- `ra` 是什么？（返回地址，记录"回来的位置"）
