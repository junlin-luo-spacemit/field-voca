## 快速开始：先记住这一句话

**程序就是一串指令，CPU 按顺序执行这些指令。**

看这个例子：

```asm
addi x5, x0, 10    # 把 10 放到 x5
addi x6, x0, 20    # 把 20 放到 x6
add  x7, x5, x6    # 把 x5 和 x6 相加，结果放到 x7
```

CPU 做了三件事：**拿到 10，拿到 20，算出 30**。就这么简单。

**只认识三个东西：**
- **CPU**：真正干活的人
- **指令**：一条小命令（如"相加"）
- **寄存器**：CPU 手边的小格子（x5、x6、x7）

## 学习建议

### ✅ 推荐做法

1. **按顺序学习**：每章都为下一章打基础
2. **动手实践**：到第9章开始写代码，第10章做项目
3. **检查理解**：每章结尾有"你现在能做什么"自测
4. **记录进度**：使用 [[学习记录]] 追踪你的学习状态

### ❌ 不推荐做法

1. ~~跳着学~~：后面的章节依赖前面的知识
2. ~~只看不练~~：到第9章必须动手
3. ~~背指令表~~：理解原理比背指令重要
4. ~~一次学完~~：每次1-2章，消化后再继续

## 为什么选择 RISC-V？

**三个关键优势：**

1. **开源免费**：规范完全公开，不需授权费
2. **设计简洁**：基础只有47条指令，容易理解
3. **模块化**：按需添加功能，灵活配置

**学习迁移：**核心概念（寄存器、栈、中断、页表）通用于所有架构。学会 RISC-V 后，理解 ARM/x86 只需查指令表差异。
