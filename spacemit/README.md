# SpacemiT 文档中心词汇

本目录用于整理来自 SpacemiT 文档中心（https://www.spacemit.com/community/document?lang=zh）的词汇、术语和学习资料。

## 目标

- 以 SpacemiT 官方文档为来源，提取重要术语和概念
- 在 `spacemit` 目录中维护词汇表、学习笔记和参考链接
- 支持后续将 RISC-V 和 SpacemiT 技术内容加入词汇库

## 推荐结构

- `spacemit/vocabulary/`：术语与定义
- `spacemit/notes/`：学习笔记和文档摘要
- `spacemit/source_links.md`：重要文档链接与分类
