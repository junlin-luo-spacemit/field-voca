# V100 (Vital Stone)

**产品系列**：Vital Stone（服务器级 RISC-V CPU）  
**核心数**：46 核（6×昆明湖 V2R2 + 40×X100）  
**主频**：最高 2.4 GHz  
**定位**：数据中心服务器级 CPU

## 定义

**SpacemiT Vital Stone V100** 是首颗完整符合 RISC-V 服务器规范的计算芯片，集成 46 个 RISC-V CPU 核心，全面兼容 RISC-V RVA23 Profile，主频最高可达 2.4 GHz，为数据中心提供强劲算力支撑。

V100 是 SpacemiT 与 K1/K3（Key Stone）**完全不同的产品线**，专为数据中心设计，定位服务器级应用。

## 为什么重要

- **首颗完整符合 RISC-V 服务器规范的芯片** — Server SoC、Server Platform、RVA23、BRS、Security Model
- **数据中心级性能** — 46 核高性能 RISC-V 处理器
- **企业级虚拟化** — 支持 Hypervisor 1.0、内存虚拟化、中断虚拟化、IOMMU
- **数据中心级安全** — 硬件信任根、安全启动、国密算法、可信计算
- **高带宽内存** — 8×DDR5-4800 通道，307 GB/s 带宽，最大 2TB
- **高速扩展** — 52 条 PCIe 5.0 通道

## 核心规格

### 处理器架构
- **CPU 核心**：**46 核**
  - **6×香山昆明湖 V2R2 CPU 核**
    - 主频：2.1 GHz
    - 架构：十三级六发射乱序流水线
    - 缓存：64KB L1 I-Cache + 64KB L1 D-Cache + 1MB L2
    - 性能：SPECint2006 ≥ 15.0/GHz
  - **40×进迭时空 X100 CPU 核**
    - 主频：2.4 GHz
    - 架构：十二级四发射乱序流水线
    - 缓存：64KB L1 I-Cache + 64KB L1 D-Cache + 2MB L2
    - 性能：SPECint2006 ≥ 9.0/GHz
    - 支持 DVFS（动态电压频率调节）
- **共享缓存**：64MB SLC Cache
- **指令集**：RISC-V RVA23 Profile

### 内存子系统
- **内存通道**：8×DDR5
- **内存类型**：DDR5 RDIMM（支持 1DPC）
- **内存速率**：4800 MT/s
- **最大带宽**：307 GB/s
- **最大容量**：2 TB（单通道最大 256GB）
- **内存保护**：80-bit DIMM（带 ECC），支持 Sideband ECC

### 高速扩展
- **PCIe 版本**：PCIe 5.0
- **PCIe 通道数**：52 条高速通道
- **配置模式**：
  - 3 组 x16 / x8x8 / x8x4x4
  - 1 组 x2x1x1
- **支持设备**：
  - GPU/NPU/FPGA 加速卡
  - NVMe SSD
  - SAS/SATA over PCIe
  - USB over PCIe

### 网络
- **以太网**：1×GMAC
- **标准**：支持 IEEE 1588

### 外围接口
- **QSPI**：1×
- **LPC/eSPI**：1×LPC + 1×eSPI
- **SPI**：3×SPI Master + 1×SPI Slave
- **I3C/I2C**：4×I3C + 12×I2C + 12×SMBUS
- **UART**：5×

### 虚拟化支持
- **CPU 虚拟化**：Hypervisor 1.0 扩展
- **内存虚拟化**：SV48×4 / SV39×4 Guest 地址翻译
- **中断虚拟化**：基于 RISC-V AIA
  - 255 个 M-mode MSI
  - 255 个 S-mode MSI
  - 63 个 VS-mode MSI
  - 每个 Hart 配置 7 个 vCPU
- **外设虚拟化**：基于 IOMMU 的 I/O 虚拟化，支持 SR-IOV

### 安全特性
- **RISC-V 安全规范**：PMP/ePMP、IOPMP (Rapid-k Model)
- **服务器安全**：可信计算、安全启动、密钥管理、生命周期管理、安全调试
- **硬件安全模块**：集成 HSM，支持硬件信任根（RoT）
- **加密算法**：AES、SHA、RSA、SM2、SM3、SM4（国密）

### RAS（可靠性/可用性/可维护性）
- **RISC-V 规范**：支持 RERI RAS 规范
- **CPU RAS**：CE/UEC 差异化处理及中断日志
- **内存 RAS**：ECC/CRC 校验、巡检、故障隔离、地址保护
- **PCIe RAS**：链路恢复、错误报告、热插拔、日志记录
- **总线 RAS**：总线数据校验/标记、SRAM ECC 保护
- **系统 RAS**：主板网络/GPU/硬盘 RAS 管理
- **RAS 管理**：遵循 Firmware First 原则

### 功耗与封装
- **TDP**：120 W
- **工作温度**：0℃ ~ 40℃
- **封装**：FCBGA，58.5mm × 75.4mm，0.94mm pitch

## V100 产品线

基于 V100 芯片的三款服务器产品：

| 产品 | 定位 | 机箱 | 处理器配置 | 核心特性 |
|------|------|------|----------|---------|
| **[[V100-C2201]]** | 通用计算服务器 | 2U | 2×V100（92 核） | 高性能、高可靠、全场景覆盖 |
| **[[V100-G5201]]** | AI 智算服务器 | 4U | 2×V100（92 核） | 8×600W GPU 卡、4×400GbE RoCE |
| **[[V100-S5236]]** | 存储服务器 | 4U | 2×V100（92 核） | 36 个硬盘槽位 |

## 与 K1/K3 对比

| 特性 | V100 (Vital Stone) | K3 (Key Stone) | K1 (Key Stone) |
|-----|-------------------|----------------|----------------|
| **产品定位** | 数据中心服务器 CPU | 边缘服务器 SoC | 边缘设备 SoC |
| **核心数** | 46 核 | 16 核（8 CPU + 8 AI） | 8 核（4 CPU + 4 AI） |
| **核心类型** | 6×昆明湖V2R2 + 40×X100 | 8×X100 + 8×A100 | 4×X60 + 4×A60 |
| **AI 算力** | 无专用 AI 核心 | 60 TOPS | 2 TOPS |
| **主频** | 2.1 / 2.4 GHz | 2.4 GHz | 1.8 GHz |
| **内存** | 8×DDR5-4800（307 GB/s） | 4×LPDDR5-6400 | 2×LPDDR4X-2400 |
| **PCIe** | PCIe 5.0（52 lanes） | PCIe 3.0/4.0 | PCIe 3.0 |
| **TDP** | 120 W | ~30-50W | ~5-10W |
| **应用场景** | 数据中心、云计算、HPC | 边缘服务器、AI 推理 | 边缘设备、IoT、机器人 |
| **产品形态** | 双路服务器 | 单板/开发板 | 单板/开发板 |

**核心差异：**
- **V100** — 服务器级 CPU，无 AI 加速，强调虚拟化和 RAS
- **K3** — 边缘 AI SoC，60 TOPS AI 算力，集成 GPU
- **K1** — 入门级边缘 SoC，2 TOPS AI 算力
