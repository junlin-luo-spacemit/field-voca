# K3

## 概述

K3 是 SpacemiT 面向高性能 AI 计算的 RISC-V 处理器，采用同构融合计算架构，集成 8 个高性能 X100 CPU 核心和 8 个超宽并行 A100 AI 核心，适用于边缘服务器、本地化大模型推理和 AI 加速终端。

## 关键参数

### CPU 与计算架构

- **架构**：RISC-V 同构融合计算技术
- **CPU**：8 × SpacemiT X100 高性能大核 @ 最大 2.4 GHz
  - 每核 64KB L1 I-Cache + 64KB L1 D-Cache
  - 2MB 共享 L2 Cache
  - 支持 RV64GCVB 指令集
- **AI 核心**：8 × A100 超宽并行计算核心
  - 整机 AI 算力：~60 TOPS
  - 支持数据类型：BF16 / FP16 / FP8 / INT8 / INT4
  - 集成矩阵运算单元、向量运算单元

### 内存与存储

- **DRAM**：64-bit LPDDR5-6400，最大容量 32 GB
- **存储接口**：
  - eMMC 5.1（HS400 模式）
  - SD 3.0（UHS-I）
  - QSPI（支持 SPI NOR / SPI NAND Flash）
- **启动模式**：SPI NAND / SPI NOR / eMMC / SD 卡（通过 STRAP 引脚配置）

### GPU 与多媒体

- **GPU**：Imagination BXE-4-64 @ 800 MHz
  - 支持 OpenCL 3.0 / OpenGL ES 3.2 / Vulkan 1.3
- **VPU**（视频处理单元）：
  - 解码：8K@30fps H.265/H.264/VP9，4K@60fps
  - 编码：8K@30fps H.265/H.264
- **ISP**（图像信号处理器）：
  - 支持最高 48MP 单摄或多摄组合
  - MIPI CSI-2 接口（4 lane × 2）

### 显示与接口

- **显示接口**：
  - MIPI DSI（4-lane）
  - eDP 1.4（4-lane，最高 5.4 Gbps/lane）
  - HDMI 2.0（最高 4K@60fps）
- **高速接口**：
  - PCIe Gen3 x4（可拆分为 x2+x2 或 x1+x1+x2）
  - USB 3.1 Gen1 × 2（可配置为 Host/Device）
  - USB 2.0 × 4
  - Dual Gigabit Ethernet (RGMII/SGMII)
- **低速接口**：
  - UART × 10
  - I²C × 10
  - SPI × 6
  - PWM × 20
  - GPIO × 128+
  - CAN-FD × 2

### 安全与电源

- **安全特性**：
  - Secure Boot
  - TrustZone 支持
  - 加密引擎（AES / RSA / ECC / SHA2 / HMAC）
  - TRNG（真随机数生成器）
  - 4K-bit eFuse
- **电源与功耗**：
  - TDP：15W ~ 25W（取决于运行点配置）
  - 支持 DVFS（动态电压频率调节）
  - 多电源域设计
- **封装**：FCBGA 23×23（1156 balls）
- **工作温度**：-40°C ~ +85°C（工业级）

## 开发资源

### SDK 选项

K3 平台提供多个 SDK，适用于不同场景：

1. **K3 Buildroot SDK** — 轻量级 Linux BSP，适用于快速嵌入式系统定制（OpenSBI + U-Boot/UEFI + Kernel + 可配置根文件系统）
2. **Bianbu SDK** — 基于 Ubuntu 的 RISC-V 优化系统，提供完整桌面环境与软件生态
3. **K3 OpenHarmony SDK (K3 OH 6.x)** — 原生 RISC-V OpenHarmony 6.x 解决方案，支持 AI 与分布式应用
4. **AI Robot SDK** — 面向智能机器人（服务机器人、人形机器人、无人机、机械臂）的完整开发套件

详见：[K3 SDK User Guide](https://raw.githubusercontent.com/spacemit-com/docs-chip/main/en/key_stone/k3/k3_sw/k3_sdk_user_guide.md)

### 硬件设计指南要点

- **DDR**：支持 LPDDR5-6400，64-bit 数据宽度，需严格遵循时序与长度匹配要求
- **电源设计**：多电源域（核心、DDR、IO），需外接 PMIC（P1 或等效方案）
- **PCB 设计**：
  - 推荐 8-10 层板
  - 阻抗控制：单端 50Ω ±10%，差分 90Ω/100Ω ±10%
  - 高速接口（PCIe Gen3、USB3、eDP）需严格阻抗控制与长度匹配
- **热设计**：TDP 15-25W，需配置散热器（参考机械 DXF 图纸）
- **回流焊温度曲线**：峰值温度 235-245°C，回流时间 35-55 秒

详见：[K3 Hardware Design Guide (PDF)](https://cdn-resource.spacemit.com/file/chip/K3/k3_hw_design_en.pdf)

### 硬件 FAQ 摘要

- **调试接口**：串口 115200 波特率，3.3V；JTAG 位于特定引脚（详见 User Manual）
- **电源管理**：支持 DVFS，多种低功耗模式
- **存储**：GMAC 支持千兆 PHY；PCIe 可转接 SATA/NVMe
- **机械信息**：K3 CoM260 核心板厚度 6.2mm（PCB 1.2mm），提供 3D 机械模型与 DXF 图纸

详见：[K3 Hardware FAQ](https://raw.githubusercontent.com/spacemit-com/docs-chip/main/en/key_stone/k3/k3_hw/k3_hw_faq.md)
