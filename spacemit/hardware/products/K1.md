# K1

## 概述

K1 是面向轻量级和消费级的 RISC-V AI 处理器系列，适用于单板和便携设备。

**官方来源**

- 产品页（参考）：https://www.spacemit.com/product/k1

## 关键参数（待补充）

- 架构：SpacemiT X60™ 双簇 RISC‑V（遵循 RISC‑V 64GCVB / RVA22）
- CPU：两簇不对称设计，Cluster0 为 Quad X60（含 AI 扩展，32K L1 / core，512KB L2 / cluster，512KB TCM），Cluster1 为 Quad X60（不含 AI 扩展） — 合计 8 核
- AI 能力：Cluster0 AI 扩展可提供 ~2.0 TOPS（整机 AI 能力取决于运行点与内存配置）
- 缓存与内存：每核 32KB L1，簇级 512KB L2；支持 Dual‑chip 32‑bit LPDDR4/LPDDR4x @ 2666 Mbps（最高可达 16 GB）及 LPDDR3 @ 1866 Mbps（最高可达 4 GB）
- 向量与扩展：RVV 1.0（VLEN 256/128，256‑bit 向量），并包含多项 AI 自定义指令（如 smt.vmadot 等）
- 存储与引导：128KB boot‑ROM；引导支持 SPI‑NAND / SPI‑NOR / eMMC / SD
- GPU：IMG BXE‑2‑32 @819MHz（支持 OpenCL 3.0 / OpenGL ES 3.2 / Vulkan 1.3）
- VPU：4K@60fps 解码，4K 编码与 1080p 同时编/解等能力（详见数据手册）
- 多媒体：Dual‑ISP（最高支持 16MP@30fps 等），硬件 JPEG 编码器
- 外设与接口：USB2.0 OTG、USB2.0 Host、USB3.0（带 USB2.0 DRD）、PCIe Gen2 (PortA x1, PortB/C x2)、eMMC5.1 HS400、SDIO、MIPI CSI (2×4‑lane)、MIPI DSI (4‑lane)、HDMI 1.4、GMAC ×2 (10/100/1000)
- GPIO / IO：GPIO 可达 128；104x 1.8V IO（IO8），24x 1.8V/3.3V 可选 IO；UART ×10，I2C ×10，SPI ×4，PWM ×20，CAN‑FD ×1 等
- 安全与调试：Secure Boot；4K‑bit eFuse；加密引擎（TRNG、AES、RSA、ECC、SHA2、HMAC）；两路 JTAG；RISC‑V PMP
- 电源与功耗：DVFS 支持，电压范围示例 0.6V–1.05V（运行点可配置以平衡性能/功耗）；多电源域与细粒度电源岛设计
- 温度与封装：工作温度 -40°C ～ +85°C（工业级）；封装选项 FCCSP 17×17（676 balls）与 FCBGA 19×19（676 balls）
- 引脚与电气：详见数据手册 Pinout（包含完整引脚表、IO 参数、AC/DC 条件与绝对最大额定值）
- 尺寸与工艺：PCIe PHY 与其他信息表明 K1 使用 22nm 工艺（文档中有注释）

## 典型用途

- 单板机与嵌入式设备
- 便携式 AI 应用
- 教学与开发套件

#### 关键章节速查

- **地址映射（Chapter 6）**：
  - DRAM @ 0x0000_0000 (2GB) + 0x1_0000_0000 (扩展)
  - 外设基址：GPIO @ 0xD401_9000，UART0-9 @ 0xD401_7000，PWM0-19 @ 0xD401_A000
  - PCIe PortA/B/C 配置空间 @ 0xCA00_0000 / 0xCA40_0000 / 0xCA80_0000
  - RCPU SRAM @ 0x0000_0000 (RCPU 视角)
  
- **启动模式（Chapter 5）**：
  - STRAP[1:0] 选择启动设备：00=SD→eMMC，01=SD→SPI NAND，10=SD→SPI NOR，11=仅 SD
  - STRAP[2] 选择下载接口：0=USB，1=UART
  - STRAP[3] 选择模式：0=启动，1=下载
  - STRAP[4] (GPIO90) 选择 Flash 电压：0=1.8V，1=3.3V

## 开发资源

### SDK 选项

K1 平台提供多个 SDK，适用于不同场景：

1. **Buildroot SDK** — 快速定制化嵌入式系统（OpenSBI + U-Boot/UEFI + Linux Kernel + 可配置根文件系统）
2. **OpenWrt SDK** — 基于 OpenWrt 23.05，适用于软路由、NAS 及网络设备
3. **Bianbu SDK** — 基于 Ubuntu 的 RISC-V 优化系统，适用于通用计算与智能终端
4. **OpenHarmony SDK (K1 OH5.0)** — 全球首个原生 RISC-V + OpenHarmony 5.0 解决方案，支持 AI 与分布式应用
5. **ROS2 SDK** — 面向智能机器人平台（服务机器人、四足机器人、无人机、机械臂等）

详见：[K1 SDK User Guide](https://raw.githubusercontent.com/spacemit-com/docs-chip/main/en/key_stone/k1/k1_sw/k1_sdk_user_guide.md)

### 硬件设计指南要点

- **DDR**：支持 LPDDR4/LPDDR4x（通过 `DDR_LP4x_SEL` 引脚选择），外部 ZQ 电阻必须为 240Ω ±1%
- **复位**：RESET_IN_N 低电平有效，需加 10nF 电容抑制抖动
- **JTAG**：支持 Primary JTAG 和 Sec2 JTAG（Sec2 支持 X60/N308 CPU）
- **时钟**：24MHz 晶振，负载电容推荐 12pF（NPO 介质）
- **启动配置**：通过 QSPI_DATA[3:0] / Strap[3:0] 配置启动设备（eMMC / SPI NOR / SPI NAND / SD）及下载接口
- **电源**：
  - 核心电压 0.9V–1.05V（动态调节，P1 PMIC BUCK1+BUCK2 组合供电）
  - DDR 电压：LPDDR4 1.1V / LPDDR4x 0.6V
  - IO 电压：1.8V (VCC18_GPIO) 或 1.8V/3.3V 可选 (VCC1833_GPIO2/3/MMC1/QSPI)
- **PCB 设计**：
  - 推荐 6 层板，阻抗控制：单端 50Ω ±10%，差分 90Ω ±10%
  - DDR 信号推荐走 L1/L4，参考完整地平面 L2/L5
  - 高速接口（USB3.0、PCIe、HDMI、MIPI）需严格阻抗控制与长度匹配

详见：[K1 Hardware Design Guide (PDF)](https://cdn-resource.spacemit.com/file/chip/K1/K1_Hardware_Design_Guide_en.pdf)

### 硬件 FAQ 摘要

- **调试接口**：串口 115200 波特率，3.3V；PRI JTAG 位于 26-pin 的 7/11/13/15 引脚；SEC JTAG 复用 SD 卡接口
- **电源管理**：P1 PMIC RTC 精度 20ppm；睡眠模式下关闭 Buck3/4 及部分 LDO；支持 RTC 闹钟唤醒
- **存储**：GMAC 仅支持千兆 PHY（不支持百兆）；PCIe 可转接 SATA（已验证 ASM1061、JMB582）
- **GPIO**：仅复用为 GPIO 功能的 IO 支持中断输入；GPIO90 启动后可作通用 IO
- **功耗**：睡眠模式功耗 28mW

详见：[K1 Hardware FAQ](https://raw.githubusercontent.com/spacemit-com/docs-chip/main/en/key_stone/k1/k1_hw/k1_hw_faq.md)
