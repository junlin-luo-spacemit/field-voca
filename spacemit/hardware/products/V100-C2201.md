# V100 计算服务器 C2201

**产品定位**：2U 双路机架式通用计算服务器  
**处理器**：2×V100（92 核）  
**适用场景**：数据中心、云计算、科学计算、行业关键业务

## 定义

**C2201** 是进迭时空基于自研 RISC-V 服务器级 CPU V100 打造的 2U 双路机架式服务器，适用于数据中心、云计算、科学计算及行业关键业务等场景。

作为一款自主研发的 2U 双路机架式服务器，C2201 基于 RISC-V 服务器级 CPU V100，全面兼容 RISC-V RVA23 Profile，整机支持双路处理器部署，具备高主频、高核心密度和高带宽 DDR5 内存。

## 为什么重要

- **高性能、高可靠、全场景覆盖的通用算力底座**
- **完整符合 RISC-V 服务器规范** — Server SoC、Server Platform、RVA23、BRS、Security Model
- **数据中心级计算性能** — 92 个高性能核心（2×V100）
- **高带宽 DDR5 内存** — 16 通道，最大 2TB，307 GB/s
- **企业级 RAS 设计** — 冗余电源、热插拔风扇、多级 RAID
- **广泛的操作系统支持** — Ubuntu、openEuler、openKylin、Red Hat、Fedora、Rocky Linux

## 核心规格

### 处理器
- **型号**：2 颗进迭时空 V100 处理器
- **核心数**：单颗 46 核，双路共 **92 核**
- **主频**：最高 2.4 GHz
- **指令集**：RISC-V RVA23 Profile

### 内存
- **插槽数**：16 个 DDR5 内存插槽
- **最大容量**：2 TB
- **内存类型**：DDR5 RDIMM
- **速率**：4800 MT/s
- **最大带宽**：单颗芯片 307 GB/s

### 存储
- **前置**：最大支持 8 块 3.5 英寸 U.2 NVMe SSD
- **内置**：最大支持 1 块 M.2 NVMe SSD
- **后置**：最大支持 2 块 2.5 英寸 SATA HDD/SSD

### 网络
- **网络控制器**：支持通过 OCP 扩展千兆、万兆网络

### I/O 扩展
- **配置选项**：
  - 最多支持 3 个 PCIe 扩展卡（×8）
  - 或 2 个 PCIe 扩展卡（×16）
  - 或 1 个 PCIe 扩展卡（×16）+ 2 个 PCIe 扩展卡（×8）

### 接口
- **前置**：2 个 USB 3.0、1 个 VGA
- **后置**：
  - 2 个电源接口
  - 1 个 VGA
  - 2 个 USB 3.0
  - 1 个 Type-C 调试口
  - 1 个管理网口

### 冷却与电源
- **风扇**：支持 N+1 冗余风扇，支持热插拔
- **电源**：标准 1600 W CRPS 铂金电源，支持 1+1 冗余

### 系统管理
- **固件**：标准 UEFI 及 ACPI 管理固件
- **BMC**：集成 BMC 管理芯片 AST2600
- **管理协议**：支持 IPMI、Redfish、SOL、KVM 虚拟媒介

### 物理规格
- **机箱**：2U 机架式服务器
- **尺寸**：820 × 447.4 × 87.8 mm（深×宽×高）
- **重量**：≤ 35 kg
- **噪声**：< 55 dB

### 环境要求
- **工作温度**：0℃～40℃
- **存储温度**：-40℃～55℃
- **相对湿度**：
  - 工作湿度：35%～80%
  - 贮存湿度：20%～93%（40℃）

## 核心特性

### 完整符合 RISC-V 服务器规范
- 遵循 Server SoC、Server Platform、RVA23 Profile、BRS 及 Security Model 等相关规范

### 数据中心级计算性能
- 整机最多配置 2 颗芯片、共计 92 个高性能核心
- 单颗芯片主频 2.4 GHz
- 单核 SPECint2006 > 9.0/GHz

### 高带宽 DDR5 内存
- 整机支持 16 个 DDR5 通道、1DPC 和主流 DDR5 RDIMM
- 速率达 4800 MT/s
- 最大带宽 307 GB/s

### 精细化内存管理
- 支持多级仲裁、QoS 策略、带宽限制和性能监控

### 服务器级虚拟化
- 支持 Hypervisor 1.0、内存与中断虚拟化
- 支持标准 AIA 中断控制器
- 支持基于 IOMMU 的外设虚拟化

### 数据中心级安全架构
- 支持硬件信任根（RoT）、安全启动
- 支持密钥与生命周期管理
- 支持安全调试、可信计算
- 支持主流国密算法

### 高可靠性设计（RAS）
- 覆盖 CPU、内存、PCIe 和电源的 RAS 机制
- 支持冗余电源、热插拔风扇
- 支持多级 RAID 及断电保护

### 高速扩展能力
- 整机提供 88 条 PCIe 5.0 Lane
- 兼容 GPU、NPU、FPGA 加速卡
- 支持 SAS/SATA、NVMe 存储设备
