# RV2768 Cluster Server

**产品形态**：2U 机架式 RISC-V 集群服务器  
**核心规模**：768 核（48×K3 芯片，每芯片 16 核）  
**AI 算力**：2880 TOPS

## 定义

**RV2768** 是 SpacemiT 推出的 **768 核 RISC-V 原生 AI 计算集群**，2U 高度、19 英寸标准机架式，搭载 **48 个 K3 处理器**（每个 K3 包含 8×X100 CPU 核心 + 8×A100 AI 核心），符合 RISC-V 国际基金会的 RVA23 规范。

RVA23 针对通用计算领域的应用处理器制定，要求支持向量（Vector）和虚拟化（Hypervisor）扩展，是面向 AI 和高性能工作负载的现代性能标准。Cluster Server 提供 768 核 RISC-V 原生算力，适合运行大量智能体和应用程序，处理海量数据的运算任务。

多计算节点集群架构和完整硬件虚拟化特性，方便多个用户使用各自的计算系统，且彼此互不干扰，用户之间有物理安全隔离特性。在向量扩展基础上，Cluster Server 支持每秒两千八百亿次（**2880 TOPS**）通用 AI 运算和 1536GB 容量内存，满足多路并发请求的 AI 推理任务。

## 为什么重要

- **最大规模 RISC-V 集群**：768 核，目前业界领先的 RISC-V 集群方案
- **极致 AI 算力**：2880 TOPS（Int8），支持大规模 AI 训练与推理
- **数据中心级**：面向企业级应用，高可用性、高扩展性
- **开放生态**：RISC-V 开源架构，无授权费用
- **国产算力**：完全自主的 RISC-V AI 计算平台

## 核心规格

### 处理器架构
- **芯片数量**：**48×K3 处理器**
- **计算节点**：最多 48 个节点，各节点之间物理安全隔离，可独立管理维护
- **CPU 核心**：**384 个 X100 CPU 核心**
  - 每个 K3 处理器：8×X100 核心
  - 单核 SPECint2006 > 9.0/GHz
  - 最大主频 2.4 GHz
  - 总核心数：48 × 8 = **384 个 CPU 核心**
- **AI 核心**：**384 个 A100 AI 核心**
  - 每个 K3 处理器：8×A100 核心
  - 单芯片 AI 算力：60 TOPS @INT4
  - 总核心数：48 × 8 = **384 个 AI 核心**
- **总核心数**：384 CPU + 384 AI = **768 核**
- **总 AI 算力**：**2880 TOPS @INT4**
  - 单 K3：60 TOPS
  - 总算力：48 × 60 = **2880 TOPS**

### 内存
- **节点内存**：LPDDR5，8 GB / 16 GB / 32 GB 容量可选
- **内存速率**：最高 6400 MT/s
- **总内存容量**：最高 **1536 GB**（48 节点 × 32 GB）
- **内存架构**：分布式内存系统（每个 K3 节点独立内存）

### 存储
- **节点存储**：NVMe SSD，PCIe 3.0 x4
- **容量选项**：64 GB / 128 GB / 256 GB（也可选配 UFS）
- **总存储容量**：最高 12.3 TB（48 × 256 GB）

### 网络
- **集群网络**：高速 Fabric（节点间互连）
- **对外网络**：多路 10GbE / 25GbE / 100GbE（取决于配置）
- **拓扑**：支持多种集群拓扑（树形、全连接等）

### 散热与功耗
- **散热**：企业级风冷/液冷系统
- **功耗**：数千瓦（TDP 取决于负载）
- **电源**：冗余电源供应（PSU）

### 机架规格
- **形态**：标准 19 英寸机架服务器
- **高度**：多 U（4U/8U/定制）
- **重量**：数十公斤

## 计算能力分析

### CPU 算力
- **768 个 RISC-V 核心** @ 1.8GHz（X60）
- **并行计算**：支持数百个并行任务
- **适用负载**：科学计算、数据分析、Web 服务集群

### AI 算力
- **2880 TOPS (Int8)** — 业界领先的 RISC-V AI 算力
- **支持模型**：
  - **小模型**：0.5B-1B 参数（单节点）
  - **中型模型**：7B-13B 参数（多节点协同）
  - **大型模型**：30B-70B 参数（集群推理）
  - **超大模型**：100B+ 参数（模型并行）
