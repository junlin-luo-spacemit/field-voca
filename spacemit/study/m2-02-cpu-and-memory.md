# CPU 子系统与内存子系统

> **本讲目标**：理解 X100 和 A100 的能力差异，理解内存层次（片上 SRAM、LPDDR5、eMMC）以及它们的速度与容量权衡。

## 一、X100：高性能 RISC-V 核

**X100** 是 K3 的通用计算核，符合 RISC-V RVA23 规范。每个 X100 核心配备：

| 组件 | 规格 | 说明 |
|---|---|---|
| L1 指令缓存 | 64 KB | 每核独立，存放指令 |
| L1 数据缓存 | 64 KB | 每核独立，存放数据 |
| L2 缓存 | 4 MB | 每簇共享（4 个核共用） |
| 向量扩展 | RVV 1.0，VLEN=256 | 支持向量计算 |
| 虚拟化扩展 | RVH 1.0，GEILEN=8 | 支持虚拟机 |

**RVA23** 是 RISC-V 应用处理器标准的 2023 版本，定义了操作系统和应用程序可以依赖的指令集。

**VLEN=256** 是指向量寄存器宽度为 256 位，可以一次处理多个数据（SIMD，Single Instruction Multiple Data）。

**GEILEN=8** 是指支持 8 个客户机（Guest）虚拟化环境，可以同时运行多个虚拟机。

**缓存层次**：L1 最快但最小（每核 128 KB），L2 更大但稍慢（每簇 4 MB），内存最大但最慢（最高 32 GB）。

## 二、A100：AI 加速核

**A100** 是 K3 的 AI 核，集成 IME 指令集扩展（Intelligent Matrix Engine，智能矩阵引擎）。

A100 专门优化矩阵运算和卷积操作，这些是神经网络推理的核心计算。

**X100 vs A100 的分工**：
- X100 运行操作系统、调度任务、处理控制逻辑。
- A100 执行神经网络层的密集计算（卷积、矩阵乘法、激活函数）。
- X100 把模型加载到内存，A100 从内存读取模型和数据并计算，结果写回内存。

**为什么不能让 X100 做 AI 计算？**  
可以，但效率低。A100 的 IME 指令一条指令可以完成 X100 需要几十条指令才能完成的矩阵乘法。

## 三、内存层次：速度与容量的权衡

K3 的内存分三层：

| 层次 | 类型 | 容量 | 速度 | 用途 |
|---|---|---|---|---|
| 片上 SRAM | On-Chip Memory | 512 KB | 最快 | 启动代码、临时数据 |
| LPDDR5 | 外部动态内存 | 最高 32 GB | 快 | 操作系统、应用、模型 |
| eMMC/SD | 外部闪存 | 最高 2 TB | 慢 | 持久化存储、文件系统 |

**512 KB SRAM**：芯片内部的静态内存，CPU 和实时核（RCPU）共享。上电后立即可用，不需要初始化。

**LPDDR5**：外部动态内存，双通道，每通道 32 位，最高速率 6400 MT/s（Million Transfers per Second，每秒百万次传输）。

**为什么是 MT/s 而不是 MHz？**  
MT/s 计数数据传输次数，MHz 计数时钟周期。LPDDR5 每个时钟周期传输多次数据，所以用 MT/s 更准确。

**eMMC**：嵌入式多媒体卡（embedded Multi-Media Card），固态存储，掉电数据不丢失。支持 HS400 模式（最高 400 MB/s）。

## 四、带宽与瓶颈

**内存带宽**是指单位时间内 CPU 可以从内存读取或写入的数据量。

K3 的 LPDDR5 双通道、每通道 32 位、6400 MT/s，理论带宽为：
```
2 通道 × 32 位 × 6400 MT/s = 2 × 4 字节 × 6400 = 51.2 GB/s
```

**为什么带宽很重要？**
- AI 推理时，A100 从内存读取模型权重和输入数据。
- 如果内存带宽不足，A100 会空转等待数据，算力发挥不出来。
- 算力再高，数据送不到计算单元也没用。

**瓶颈判断**：一个任务能不能跑快，取决于算力、带宽、容量三者中最紧的那个。
