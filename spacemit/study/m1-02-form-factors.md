# M1 · 第二课：同一颗芯片的多种形态

同一颗芯片，能做成不同形态的产品。形态决定了卖给谁。

## 一、K3 有四种形态

同一颗 K3 芯片，做成四种产品。别说全，**先学会两两区分**。

### 第一刀：要不要自己设计板子

| | 客户设计载板 | 买了就能用 |
|---|---|---|
| 形态 | **CoM260** | Pico-ITX、Shelf、RV2768 |

CoM260 卖的是**模组**：芯片、内存、存储封在一块小板上，你拿回去插到自己的载板上。

另外三种都是成品，不需要你设计电路板。

**所以「做整机的厂商」这个词，指的就是 CoM260 的客户。** 他们买模组，做自己的整机。

### 第二刀：一块板，还是一整台机器

剩下三种里，再分两层：

| | 一块板 | 一整台机器 |
|---|---|---|
| 形态 | **Pico-ITX** | Shelf、RV2768 |

Pico-ITX 是单板计算机，你自己配外壳和电源，装进设备里。

Shelf 和 RV2768 是机架服务器，插到机柜里就能跑。

### 第三刀：编译，还是推理

Shelf 和 RV2768 都装多个 K3，都是机架服务器。**唯一区别是拿来干什么。**

| | **Shelf** | **RV2768** |
|---|---|---|
| 干什么 | 编译代码、跑软件兼容性测试 | 跑 AI 推理 |
| 为什么选它 | 原生编译比 x86 上跑 QEMU 快 10 倍以上 | 48 个节点堆算力，跑并发推理 |
| 规模 | N10 / N48 两款 | 48 个节点 |

**一句话记法：编译找 Shelf，推理找 RV2768。**

这两个名字不好记，可以这样想：Shelf 是「架子」，一堆代码往上摆着编译；RV2768 的数字 2768 听起来更"重"，负责重负载的推理。

### 三刀串起来

判断一个 K3 产品是哪一种，按顺序问：

1. **要客户自己设计板子吗？** 要 → CoM260。
2. **是一块板还是一台机器？** 板 → Pico-ITX。
3. **拿来编译还是推理？** 编译 → Shelf；推理 → RV2768。

## 二、CoM260：卖的是模组

核心模组把芯片、内存、存储封装成一块小板。

客户拿到模组，只需要设计自己的载板。

产品资料的原话是"核心模组 + 通用载板形态"。

这样一颗芯片能卖给做机器人的、做一体机的、做自助设备的。每家载板不同，模组相同。

## 三、Pico-ITX：卖的是单板

Pico-ITX 是完整可用的单板计算机。

- 尺寸 2.5 英寸 Pico-ITX plus
- 板载 UFS 存储
- 双 M.2 扩展槽
- 全功能 Type-C，一根线供电和显示

买回去直接装进设备，不用再设计载板。

## 四、Shelf 和 RV2768：卖的是节点数

这两个都是机架服务器，但定位不同。

**K3 Shelf** 分 N10 和 N48 两款。

- 单节点 8 核 X100 加 8 核 A100
- 单节点功耗 15–25 W
- 面向编译集群和软件兼容性测试

**RV2768** 装 48 个 K3。

- 2U 高度，19 英寸标准机架
- 面向大规模 AI 推理

产品资料给出的卖点是编译性能：原生编译比 x86 平台 QEMU 仿真快 10 倍以上。

## 五、K1 的形态更多

K1 系列有 8 个产品，形态跨度很大。

| 产品 | 形态 |
|---|---|
| MUSE Book | RISC-V 笔记本电脑 |
| MUSE Pi / Pi Pro | 单板计算机 |
| MUSE Card | 小型单板 |
| MUSE Box | 盒子 |
| MUSE Paper | 平板 |
| MUSE Shelf | 集群服务器 |
| RISC-V 实验箱 | 教学实验套件 |

产品资料称 MUSE Book 是"全球首款可量产的 RISC-V 笔记本电脑"。
