# 测验模板使用说明

`_template.html` 是测验的骨架。CSS、交互逻辑、诊断机制都已固定，**只需填写 `DATA` 数组**。

## 为什么要有模板

M1 的测验功能是边对话边加的。如果没有模板，M2 从头写会出现：

- 字段名不一致（`rv` 写成 `review`、`sai` 写成 `saIndex`）
- `localStorage` 键名不同（`spacemit.m2.history` 写成 `m2_quiz_history`），跨模块统计就断了
- 优先级排序逻辑各写一套，行为不一致

模板把这些固定下来。

## 怎么用

### 1. 复制并改名

```powershell
Copy-Item spacemit\study\quiz\_template.html spacemit\study\quiz\m2-recap.html
```

### 2. 替换占位符

在文件里全局替换这六处：

| 占位符 | 替换成 | 例 |
|---|---|---|
| `__MODULE__` | 模块编号 | `M2` |
| `__MODULE_TITLE__` | 模块主题 | `一颗芯片里有什么` |
| `__MODULE_KEY__` | 历史存储键（小写、无空格） | `m2` |
| `__N_BASIC__` | 基础题数量 | `5` |
| `__N_TRAP__` | 认陷阱数量 | `7` |
| `__N_SA__` | 自评项数量 | `16` |
| `__N_TOTAL__` | 选择题总数（基础 + 认陷阱） | `12` |
| `__LESSON_LINKS__` | 课程链接（HTML） | `\u003ca href="../m2-01-xxx.md"\u003e标题\u003c/a\u003e · …` |

### 3. 填写 DATA

三段结构：`一、基础题` → `二、认陷阱` → `三、自评`。

**每道选择题的字段：**

| 字段 | 必填 | 内容 |
|---|---|---|
| `q` | 是 | 题干，一句话 |
| `sai` | 是 | 对应第几条自评（从 0 开始）。必须真的对得上 |
| `opts` | 是 | 四个选项 |
| `a` | 是 | 正确项下标 0–3 |
| `e` | 是 | 解析：为什么这个对 |
| `wrong` | 是 | 逐项说明每个错误选项错在哪，键为下标 |
| `src` | 是 | 库 · 路径 · 章节 |
| `rv` | 是 | 从课文抽 2–3 句原文（抄，不要改写） |

**自评项只有一个字段：** `k`（知识点名称）。

### 4. 对齐检查

填完后确认两件事：

- **每条自评至少有一道题对应。** 有悬空的就删掉那条自评，或者补一道题。
- **`sai` 值与自评项下标真的对应。** 最容易错在这里：题号不是自评序号。

用这条命令快速核对：

```powershell
Select-String -LiteralPath spacemit\study\quiz\m2-recap.html -Pattern 'sai:|k: "'
```

输出的 `sai` 值应该都在 `0 … (自评条数−1)` 范围内，且不重复漏项。

### 5. 验证

按 [STYLE.md](../STYLE.md) 的「交付前必须实测的场景」逐项跑：

- 全部答对
- 部分答错
- 同一题连错两次（应出现重写提示）
- 答错且自评标「懂了」（应排优先级 1）
- 自评从「懂了」改成「没懂」（清单应重排）
- 复制诊断摘要
- 重做（页面清空、历史保留）

**先清掉测试产生的历史**，否则学习者第一次做会看到"错第 N 次"：

```javascript
localStorage.removeItem('spacemit.m2.history')
```

## 模板里已经做好的事

不用重写，`_template.html` 自带的：

- 响应式深/浅色主题
- 点击即判分、已答锁定、不重复计分
- 键盘可操作（Tab 聚焦、Enter/空格触发）
- 每题作答后显示：判定、正确答案、逐项解析、来源、内嵌回看原文
- 完成时显示总分、分档评语、分组正确率
- 三级优先级「需回看」清单（答错且标懂了 / 答错 / 自评有疑问）
- 自评改动后清单实时重排
- `localStorage` 跨次错误计数，错 2 次触发讲解重写提示
- 复制诊断摘要（含剪贴板兜底）
- 重做清页面状态、保留历史

## 已知限制

- 历史只存本机浏览器，换机器或清缓存会丢。
- 助教不主动介入，靠复制摘要作为桥梁。
- 模板不是零配置：填 `DATA` 仍需人工判断题干措辞、选项难度、解析质量——这些是模板给不了的。
