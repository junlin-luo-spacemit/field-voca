# 片上存储：Boot ROM 与 SRAM

> **本讲目标**：知道 K3 芯片内部有两块小存储（Boot ROM 和 SRAM），它们各是什么、为什么启动离不开它们。
>
> **📌 说明**：本讲只讲片上存储本身。**完整的启动链路、启动模式和固件刷写见 [M4](./m4-01-boot-flow.md)**，安全启动的细节见 [M4 第三课](./m4-03-secure-boot-and-opensbi.md)。本模块以 **K3** 为例，但片上存储的作用适用于所有 SoC 芯片。

## 一、K3 有两块片上存储

芯片内部自带两块很小的存储，不占用外部存储接口：

| 类型 | 容量 | 特点 | 用途 |
|---|---|---|---|
| **[Boot ROM](GLOSSARY.md#boot-rom)** | 128 KB | 只读，出厂固化 | 存放最初的引导代码 |
| **[SRAM](GLOSSARY.md#sram)** | 512 KB | 可读写，掉电丢失 | 启动早期临时运行代码 |

**关键对比**：Boot ROM 用来**存**最初的代码，SRAM 用来**跑**最初的代码。两者配合，芯片才有一个能动的起点。

## 二、Boot ROM：芯片自带的启动代码

**Boot ROM**（启动只读存储器）是芯片出厂时就固化好的只读存储。

- **不可修改**：出厂烧好，之后谁也改不了。这既是限制，也是信任的起点（见 M4 安全启动）。
- **存放一级引导代码**：CPU 上电后的第一条指令就来自这里。
- **支持从多种介质启动**：eMMC、UFS、SD、QSPI NOR Flash、USB、UART 下载。
- **容量只有 128 KB**：这条限制直接决定了启动必须分阶段。

## 三、SRAM：启动早期的工作内存

**SRAM**（静态随机存取存储器）是芯片内部的高速可读写内存。

- **上电后立即可用**：不需要初始化，这是它最大的价值。
- **主 CPU 和实时核（RCPU）共享**：同一块 512 KB，两边都能用。
- **掉电数据丢失**：不是存储设备，不能持久保存任何东西。
- **容量只有 512 KB**：只够在启动早期临时使用。

## 四、为什么这两块小存储决定了"必须多阶段启动"

原因有两个，都来自上面两块存储的限制：

1. **Boot ROM 只有 128 KB**，放不下完整的操作系统
2. **[LPDDR5](GLOSSARY.md#lpddr5) 上电后需要初始化才能用**，而初始化代码本身需要一个能跑的地方 → 就是 SRAM

所以启动只能这样走：ROM 里的小段代码先跑起来 → 初始化内存 → 再从外部存储加载大系统。

**片上存储在启动中的角色**：

```
上电
  ↓
┌──────────────┐
│  Boot ROM    │ ← CPU 从这里开始执行（128 KB，只读）
│  (芯片内部)   │   - 决定从哪个介质启动
└──────┬───────┘   - 把引导程序加载到 SRAM
       ↓
┌──────────────┐
│    SRAM      │ ← 引导程序在这里运行（512 KB，可读写）
│  (芯片内部)   │   - 初始化 LPDDR5
└──────┬───────┘   - 为后续阶段准备内存
       ↓
┌──────────────┐
│   LPDDR5     │ ← 内存就绪后，系统在这里运行
│  (板上内存)   │   - 加载操作系统
└──────────────┘   - 运行应用程序
```

> 这条链路每一步叫什么、谁加载谁，见 [M4 第一课：启动流程](./m4-01-boot-flow.md)。

## 五、启动概览（详情见 M4）

Boot ROM 能从上表列出的多种介质启动，包括 eMMC、UFS、SD 卡、QSPI Flash，以及通过 USB 或 UART 接收固件。

**启动介质怎么选、SD 卡为什么优先、怎么刷固件**，见 [M4 第二课：启动模式与固件刷写](./m4-02-boot-modes-and-flashing.md)。

## 六、安全启动概览（详情见 M4）

K3 的[安全启动](GLOSSARY.md#安全启动)依赖芯片内的 **[eFuse](GLOSSARY.md#efuse)**（electronic fuse，电子熔断丝）：

- eFuse 存放"哪把密钥可信"的信息（根公钥的哈希值），**写入后不可逆**
- 每个启动阶段都验证下一阶段的签名，验证失败就停止启动

**为什么要这样做、量产前要注意什么**，见 [M4 第三课：安全启动与固件保护](./m4-03-secure-boot-and-opensbi.md)。
