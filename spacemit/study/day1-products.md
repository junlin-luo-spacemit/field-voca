# Day 1 学习材料：SpacemiT 产品全景

## 学习目标

能用自己的话说清"SpacemiT 有哪两条芯片线、每条线有什么产品、为什么这样分"。

---

## 核心内容

### 两大芯片系列

| 系列 | 记忆法 | 芯片里有什么 | 卖给谁 |
|------|--------|-------------|--------|
| **Key Stone（K 系列）** | 带 AI 的小钢炮 | CPU + **AI 核心**（芯片自带） | 边缘设备：摄像头、机器人、智能硬件 |
| **Vital Stone（V 系列）** | 纯 CPU 大卡车 | **只有 CPU**，无 AI 核心 | 数据中心：云、虚拟化、数据库 |

**一句话**：K 系列自己能做 AI；V 系列做 AI 必须外接 GPU 卡。

---

### 三颗芯片

#### K1（第一代，边缘 AI）
- **8 核 = 4×X60 通用核 + 4×A60 智能计算核**
- A60 是独立的 AI 核，不是"X60 加扩展"
- 算力：50 KDMIPS CPU + **2 TOPS** AI
- 能跑：0.5B–1B 本地模型
- 内存：LPDDR4X

#### K3（第二代，边缘服务器）
- **16 核 = 8×X100 CPU + 8×A100 AI**
- 算力：130 KDMIPS + **60 TOPS**
- 能跑：**30B** 模型
- 内存：LPDDR5-6400

#### V100（数据中心，纯 CPU）
- **46 核 = 6×昆明湖 V2R2 + 40×X100**
- **没有 AI 核心**
- 内存：**DDR5-4800**（服务器内存，非 LPDDR），最大 2 TB

---

### K 系列产品线

| 产品 | 形态 | 定位 |
|------|------|------|
| MUSE-Pi | 开发板 | 像树莓派 |
| MUSE-Book | 笔记本 | 便携 AI 终端 |
| MUSE-Card | 计算卡 | 插进别人机器里 |
| MUSE-BOX | 迷你主机 | 小体积工控 |
| K3 Pico-ITX | 工业主板 | 边缘服务器 |
| **RV2768** | 2U 机架 | **48×K3 集群** |

#### RV2768 关键规格

| 项目 | 数值 |
|------|------|
| 芯片 | **48 颗 K3**（早期文档错写 96 颗 K1） |
| 核心 | 384 CPU + 384 AI = **768 核** |
| AI 算力 | **2880 TOPS**（48×60） |
| 内存 | LPDDR5-6400，最高 **1536 GB** |
| 形态 | 2U 机架，24 个计算模块 |

---

### V 系列产品线（三款，别混）

| 型号 | 用途 | 关键点 |
|------|------|--------|
| **C2201** | 通用计算 | 云平台、虚拟化、数据库。无 GPU 槽 |
| **G5201** | AI 智算 | 4U，8 个 PCIe 槽。**出厂不带显卡** |
| **S5236** | 存储 | 4U，36 个硬盘位 |

---

### 同构融合技术（SpacemiT 自研）

**定义**：用统一 RISC-V 指令集驱动三种算力

- **Scalar 标量** → 普通程序（打开文件、运行应用）
- **Vector 向量** → 批量数据（图片、音频处理）
- **Matrix 矩阵** → AI 推理（识别图片、语音转文字）

**类比**：全队说中文（同构融合）vs 需要翻译官的中英混合团队（传统 CPU+GPU 异构）

**Key Stone 独有**，V100 没有 AI 核心，不能用。

---

### 选型决策树

```
需求是什么？
│
├─ 边缘设备做 AI
│   ├─ 轻量（1B 模型）→ K1
│   └─ 较重（30B 模型）→ K3
│
├─ 大规模 AI 推理（100B+）→ RV2768
│
└─ 数据中心
    ├─ 云/虚拟化/数据库 → V100-C2201
    ├─ AI 训练（要买显卡）→ V100-G5201
    └─ 海量存储 → V100-S5236
```

---

## 易错点

| 错误 | 正确 |
|------|------|
| K3 CPU 是 X60 | K3 是 **X100**，X60 是 K1 的 |
| K1 是 8×X60 + A60（算成 12 核） | K1 是 4×X60 + 4×A60 = **8 核** |
| Bianbu 2.x 基于 Ubuntu 23.10 | 2.x 基于 **Ubuntu 24.04.1** |
| Bianbu 4.x 也支持 K1 | 4.x **仅支持 K3** |
| G5201 出厂带 8 张 GPU 卡 | 出厂无卡，**8 个 PCIe 槽需自购** |
