# 原子词条索引（Atoms Index）

## 什么是原子词条（Atoms）？

原子词条是 SpacemiT 知识库中**最核心**的技术概念，具有以下特征：
1. **跨领域引用**：在多个领域（硬件/软件/AI/工具）中被频繁引用
2. **基础性**：是理解其他概念的前置知识
3. **SpacemiT 特色**：SpacemiT 独有或重点强调的技术
4. **深度解析**：需要独立页面进行完整阐述

**其他概念请查看各领域的 vocabulary.md 和详细页**。
