# 云服务词汇表

> 涵盖：SpacemiT 云平台、设备管理
> 来源：SpacemiT 文档中心 Cloud 分类

---

## 云平台（Cloud Platform）

### SpacemiT Cloud / SpacemiT 云
SpacemiT 的云服务平台，提供设备管理、模型部署与计算资源池化服务。详见 [[SpacemiT-Cloud]]。

### Device Management / 设备管理
远程管理和监控 SpacemiT 硬件设备。

### Model Deployment / 模型部署
在云端管理和分发 AI 模型到边缘设备。

---

## 云服务（Cloud Services）

### Compute Pool / 计算资源池
集中管理的计算资源，可动态分配。

### Monitoring / 监控
实时监控设备状态、性能指标、资源使用。
